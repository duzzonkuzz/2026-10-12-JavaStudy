1일차 (2026-10-12)

1. 자바 프로그램 실행 과정 

소스 코드(.java) → [javac] 컴파일 → 바이트코드(.class) → [JVM] 실행

2. 소스 코드와 바이트코드의 차이

- 소스 코드 (.java): 개발자가 직접 작성하는 코드. 사람이 읽을 수 있음.
- 바이트코드 (.class): javac가 소스 코드를 변환한 결과물. JVM 전용 중간 언어로, 사람이 직접 작성하거나 수정하지 않음.

3. JDK / JRE / JVM 관계


JDK ⊃ JRE ⊃ JVM


- JVM: 바이트코드를 실행하는 가상 머신
- JRE: JVM + 기본 라이브러리 (실행 전용)
- JDK: JRE + 개발 도구(javac 등) → 개발자는 JDK 설치

4. JVM

JVM은 크게 세 부분으로 나뉜다.

 클래스 로더
   .class 파일을 메모리로 불러온다. 실행 전 준비 단계.

 런타임 데이터 영역
   프로그램이 실행되는 동안 쓰는 메모리 공간. 변수 같은 데이터가 여기 저장된다.

 실행 엔진
   - 인터프리터: 바이트코드를 한 줄씩 기계어로 바꿔서 바로 실행한다. 시작은 빠르지만 반복되는 코드도 매번 번역해서 느리다.
   - JIT 컴파일러: 자주 실행되는 코드를 통째로 기계어로 바꿔 저장해두고 재사용한다. 인터프리터의 속도 문제를 보완한다.
   - 가비지 컬렉터(GC): 더 이상 쓰지 않는 메모리를 자동으로 정리한다.


2일차 (2026-10-13)

1. 변수

값을 저장하는 메모리 공간에 붙인 이름. 프로그램이 실행되는 동안 값을 기억해두고 계속 바꿔 쓰기 위해 사용한다.

- 선언: int hp;
- 초기화: 처음으로 값을 넣는 것

2. 기본 자료형

자료형에 따라 차지하는 메모리 크기가 다르다.

| 종류 | 자료형 | 크기 |
| 정수 | byte / short / int / long | 1 / 2 / 4 / 8 byte |
| 실수 | float / double | 4 / 8 byte |
| 문자 | char | 2 byte |
| 논리 | boolean | true / false |

- 정수는 int, 실수는 double이 기본
- long은 값 뒤에 L, float는 f를 붙인다. (100L, 3.14f)
- 문자열은 기본형이 아니라 String을 사용한다.

3. 식별자 규칙

- 숫자로 시작할 수 없다.
- 대소문자를 구분한다.
- 특수문자는 _와 $만 사용 가능하다.
- 키워드(int, class 등)는 사용할 수 없다.
- 관례: 변수는 소문자로 시작(myAge), 클래스는 대문자로 시작(Scanner)

4. 키보드 입력 (Scanner)


import java.util.Scanner;

Scanner scan = new Scanner(System.in);
int a = scan.nextInt();   // 입력한 정수를 a에 저장


- Scanner는 java.util에 있어서 import가 필요하다. (Ctrl + Shift + O)

5. 메모리와 DB

- 메모리(RAM): 실행 중 사용하는 공간. 빠르지만 프로그램이 끝나면 사라진다. 변수가 저장되는 곳.
- DB / 하드: 오래 보관하는 공간. 꺼져도 남는다.



3일차 (2026-10-14)

1. 연산 우선순위

수학과 같이 곱셈·나눗셈이 덧셈·뺄셈보다 먼저 계산된다.

- 괄호 ( ) → *, /, % → +, -
- 우선순위가 같으면 왼쪽부터 계산

```java
int a = 5 + 3 * 2;     // 11
int b = (5 + 3) * 2;   // 16
```

헷갈릴 때는 괄호로 순서를 명확하게 하는 게 좋다.

2. 증감 연산자 (전위 / 후위)

++는 1 증가, --는 1 감소.

- 전위 ++a: 먼저 증가시키고 그 값을 사용
- 후위 a++: 현재 값을 먼저 사용하고 나중에 증가

```java
int a = 5;
int b = ++a;   // a=6, b=6

int c = 5;
int d = c++;   // c=6, d=5
```

단독으로 쓰면(a++; / ++a;) 결과가 같지만, 다른 연산과 함께 쓰면 결과가 달라진다.

3. 문자열 결합 연산자 (+)

한쪽이라도 문자열이면 더하기가 아니라 이어 붙이기가 되고, 결과는 문자열이 된다.

```java
"점수: " + 100     // "점수: 100"
1 + 2 + "3"        // "33"  (1+2=3 먼저 계산 후 결합)
"1" + 2 + 3        // "123" (처음부터 문자열이라 계속 결합)
```

- 왼쪽부터 순서대로 계산되는 점에 주의
- 문자열에는 -, *, / 사용 불가 ("10" - 5는 에러)
